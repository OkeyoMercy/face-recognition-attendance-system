# Face Recognition Attendance System

A Django-based attendance management system that uses facial recognition to identify students and record their attendance.

## Features

- Student registration and face encoding.
- Camera-based facial recognition.
- Attendance recording and tracking.
- Unit, timetable, and venue management.
- Attendance dashboard.
- CSV attendance report export.
- Customised Django administration interface.

## Technologies Used

- Python
- Django
- OpenCV
- face_recognition
- NumPy
- SQLite
- HTML and CSS
- JavaScript
